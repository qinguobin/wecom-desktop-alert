把企业微信里**需要你处理**的消息钉在桌面最上层，处理完一键勾掉（顺带清掉企微里的未读角标）。

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 随企业微信自动启停 | ✅ | 打开企微自动弹出小组件，关掉企微自动退出（待办已保存） |
| 一会话一张卡片 | ✅ | 同一个联系人/群的多条消息合并成一张卡，按时间从上到下排列 |

## 二、消息的四种进法（重要，请先读）

### 1. 屏幕捕获（主通道，全自动）

每 3 秒截图企微窗口 → 系统 OCR → 发现会话列表有新内容 → AI 判断 → 钉到桌面。
**不需要你做任何操作。**

但有硬边界（全部实测过）：

| 企微窗口状态 | 能不能读 | 说明 |
| --- | --- | --- |
| 显示在屏幕 + 停在「消息」页 | ✅ | 哪怕被别的窗口盖住、或在另一个虚拟桌面，**都不影响** |
| 被其它窗口完全盖住 | ✅ | `PrintWindow` 强制重渲染，不受遮挡影响 |
| 在另一个虚拟桌面 | ✅ | 同上 |
| 切到「工作台/文档」等页 | ❌ | 屏幕上没渲染消息列表，没像素就没内容 |
| **最小化到任务栏** | ❌ | 企微停止渲染，只能拿到冻结帧（实测 70 秒纹丝不动） |
| **移到屏幕外**（未最小化） | ❌ | 同样冻结（移回屏幕内立刻恢复） |

> 所以用法是：**企微开着、停在消息页、别最小化**。
> 想让它"眼不见为净"，**用别的窗口盖住它**，或者**扔到另一个虚拟桌面**——这两种都照读不误。

当前状态会实时显示在标题栏上：`企微已最小化（暂停）` / `企微不在消息页`。

### 2. 剪贴板（辅助，最精确）

在企微里**右键消息 → 复制**即可。

### 3. 全局热键（辅助，推荐）

在企微里**选中那段消息文字 → 按 `Ctrl+Alt+Space`**，程序替你在企微内执行复制。
只在焦点属于企微窗口时生效，不会把 Ctrl+C 打到别的程序里。

### 4. 会话存档 API（预留，唯一根治方案）

见 [第六节](#六想让它真正的只要登录就一定读到)。

## 三、安装与启动

> 当前环境已就绪（Python 3.12 在 `D:\Python312`，依赖已装），直接用即可。
> 新机器上先跑 `Install.bat`。

1. 编辑 `config.json`，填你的企微昵称（群内 @ 识别靠它）：

```json
"filter": { "my_names": ["张三"] }
```

2. 双击 `Start.bat` 启动（右上角出现小组件）
3. 双击 `Enable-AutoStart.bat` —— 之后开机静默常驻，打开企业微信即自动弹出

> ⚠️ 程序**必须由你双击启动**，或等下次开机自动起来。
> 从自动化/终端环境里拉起的进程会被系统回收，存活不下来（实测 `Start-Process`、
> `wscript`、`schtasks` 全被拦截）。

其他入口：

- `Start-Demo.bat`：不依赖企业微信，循环注入示例消息看效果
- `Start-Console.bat`：带控制台的排错版
- `Start-Watchdog.bat`：单独跑看门狗（控制台可见）
- `Disable-AutoStart.bat`：取消自启

## 四、接入 AI（可选）

不配也能用，自动降级为**关键词规则**。
想要更准，填任意 OpenAI 兼容服务（DeepSeek / 通义 / Kimi / 智谱 / 本地 Ollama 都行）：

```json
"ai": {
  "api_base": "https://api.deepseek.com/v1",
  "api_key": "sk-xxxxxxxx",
  "model": "deepseek-chat",
  "timeout": 20
}
```

AI 输出：是否需要处理 + 优先级（高/中/低）+ 一句话理由，理由会显示在卡片上。

## 五、勾掉时如何消掉企微角标

企微没有开放"标记已读"的接口，程序用两级策略（都失败也只是记日志，不影响使用）：

1. UIA：找会话 → 右键 → "标记为已读"（**Flutter 下基本用不上**）
2. **快捷键（主路线）**：激活企微 → `Ctrl+F` 唤起搜索 → 粘贴会话名 → 回车打开会话
   → 角标清除 → `Esc` → 切回你原来的窗口

`Ctrl+F` 这条实测通过，可用 `tools/test_hotkey.py` 复验。
如果某台机器上不灵：

- `tools/test_hotkey.py k` 试试 `Ctrl+K`，好用就把 `mark_read.search_key` 改成 `"k"`
- 或直接鼠标点击搜索框：设 `mark_read.click_search_offset = [160, 24]`

## 六、想让它真正的「只要登录就一定读到」

**唯一的路：企业微信官方的「会话内容存档」。**

这是官方的服务端能力，直接拿聊天记录，**跟客户端窗口状态完全无关**——
企微最小化、锁屏、甚至没开电脑都能读到。

它是付费功能，需要你们**企业管理员**在企微管理后台开通。

在此之前本项目用的是屏幕 OCR，必须先说清它为什么被卡住：

| 路径 | 结论 | 证据 |
| --- | --- | --- |
| 客户端 UI 自动化 | ❌ | 企微是 Flutter，UIA 只能读到 2 个空节点 |
| 官方连接器 `wecom-cli` | ❌ | `errcode 853006`「企业未开通」 |
| Windows 系统通知 | ❌ | 探针 240 秒，一条都没弹（本机企微不弹通知） |
| **屏幕截图 + OCR** | ⚠️ | 可用，但窗口必须可见 |

**853006 的判断过程**（省了我半天）：用 4 个 chat-id 试，其中 3 个是瞎编的
（`wmXXXX` / `test`），**全部返回同一个错误码** —— 说明拦截发生在校验 ID 之前，
是**企业层级的功能开关**，不是参数问题、也不是授权问题。

`apiread.py` 已经写好了：企业一开通就能用，且在遇到 853006 时会**自动静默停用**，
不会刷屏报错。开通后只需：

```json
"capture": {
  "api": true,
  "api_chat_ids": ["同事A", "项目群"],
  "api_interval_seconds": 20
}
```

## 七、个人微信呢

**读不到。** 而且比企业微信更封闭——
**微信官方就没有开放"读取个人聊天记录"的 API**（只开放了公众号 / 小程序 / 企业微信三类）。

所以用户问"需要我的微信做什么授权吗"，答案是：**不需要，也无处可授权**——
不是权限问题，是这个产品能力根本不存在。

实测证据见 [docs/02-个人微信读取实测.md](docs/02-个人微信读取实测.md)：
Qt + 自绘（UIA 空）、本地 12 个库全部 SQLCipher 加密、最小化时截图是纯色空图。

## 九、已知限制（说在前面）

1. **企微最小化 / 移出屏幕 / 不在消息页时读不到** —— 这是操作系统 + Flutter 的
   硬性行为，绕不过去。想看不见它，用别的窗口盖住或扔到另一个虚拟桌面。
2. **无法用官方接口读聊天记录**（企业未开通会话存档 853006）。
3. **个人微信读不到**（官方无此 API）。
4. 勾掉后"消角标"依赖企微搜索框，企微改版可能需要调整
   `mark_read.search_key` / `click_search_offset`。
5. OCR 识别会有错别字，程序已做模糊匹配；若要更准，可在
   `filter.group_senders` 里补全群名。
6. 程序必须由你双击启动，自动化环境拉起的进程活不下来。
7. 程序只在本机运行，除你配置的 AI 接口外不发送任何数据。
