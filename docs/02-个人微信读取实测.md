# 实测记录 02 · 个人微信（WeChat）能不能读

结论：**读不到，而且比企业微信更封闭——因为个人微信官方就没有开放读取聊天记录的 API。**

---

## 一、没有可授权的东西

微信官方只开放了三类 API：**公众号、小程序、企业微信**。
**个人账号的聊天记录不在其中**——所以流程上不存在"授权某个应用去读我的微信消息"
这个动作，翻遍微信设置也找不到这个开关。

> 用户问："需要我的微信做什么授权吗？"
> 答：不需要，也无处可授权。这不是权限问题，是这个产品能力根本不存在。

WorkBuddy 连接器市场全量搜索的结果里，也确实**没有微信连接器**
（只有 QQ邮箱 / ima / 钉钉 / 福帮手 / Notion / 腾讯企点客服 / CloudBase /
微盛企微管家SCRM / 秒哒，后两者是企微生态，不是个人微信）。

## 二、本机微信 4.0 的四项实测

### 1. 主窗口是 Qt + 自绘，UIA 控件树完全为空

```
主窗口 class = Qt51514QWindowIcon      （微信 4.0 改用 Qt 框架）
  └─ 唯一子窗口 class = MMUIRenderSubWindow   （自绘渲染层）
      └─ UIA 遍历结果：0 个节点
```

和企业微信（Flutter）一样，走 UIA 路线是死路。
复现脚本：`tools/probe_wechat_uia.py`

### 3. 最小化时截图是纯色空图

```

```

和企业微信完全一致的冻结行为。

### 4. 顺带修了 `screen.py` 的一个真 bug

测微信时发现：`GetWindowRect` 在最小化时**不一定**返回 -32000 那种典型坐标。
微信最小化后返回的是 **`314x50`** 的小矩形，导致我原来的判断失效：

```python
# 错误：以为最小化一定是 -32000
if r.left <= -20000 or r.top <= -20000:
    r = plc.rcNormalPosition

# 正确：直接用 IsIconic 判断
if r.left <= -20000 or r.top <= -20000 or user32.IsIconic(hwnd):
    r = plc.rcNormalPosition
```

这个 bug 对企微同样存在。
